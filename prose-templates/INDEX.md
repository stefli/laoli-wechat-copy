# 行文模板索引（开写前必选）

用法：开写前从下表挑 **1 个** `id`，写入本篇 `FACTS.md` / `IMAGE-NOTES.txt` 顶行：
`本篇行文：<id> · <中文名>`
再 **按该模板文件全文约束** 写正文。禁止只记名字却仍用默认腔。

与「文章结构骨架」分开选：骨架管章节怎么排，模板管怎么说话。当日第二篇：骨架 id 与行文 id **都不得**与第一篇相同；也勿与近 2～3 篇行文 id 相同。
